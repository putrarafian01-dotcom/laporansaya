# laporansaya

ini adalah laporan web saya

- Dashboard HTML: [index (4).html](https://github.com/putrarafian01-dotcom/laporansaya/blob/main/index%20(4).html)

Quick start

- Open `index (4).html` directly in a browser, or serve the repo root with a static server and open the file:

```bash
python -m http.server 8000
# then open http://localhost:8000/index%20(4).html
```

Notes

- The page parses Excel files (SheetJS) to populate per-store KPIs and can optionally sync data via jsonblob.com.
- There is a CI workflow `.github/workflows/jekyll-docker.yml` present but the repo is a standalone static HTML page.
